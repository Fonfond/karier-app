# UI/UX-концепция «Карьер» (v2)

Принцип: **интерфейс для человека в каске, в перчатках, на солнце и в темноте, без сети.** Всё остальное — следствие.

---

## 1. Принципы

| Принцип | Что это значит в макете |
|---|---|
| **Карта — это главный экран** | 70% сценариев начинаются с «найди объект на карте». Остальное — слои поверх неё (bottom sheet), а не отдельные страницы |
| **Тёмная тема по умолчанию** | Ночная смена, кабина, яркое солнце на экране. Светлая — переключатель, запоминается на устройстве |
| **Перчатки и большой палец** | Тач-цели ≥ 48×48 px, основные действия в нижней трети экрана, свайпы вместо мелких крестиков |
| **Офлайн — норма** | Индикатор состояния всегда на виду, очередь изменений видна, «нет сети» не выглядит как ошибка |
| **Два режима, а не два приложения** | «Работа» (все) и «Правка схемы» (админ) — визуально разные режимы с явным индикатором, чтобы не переподключить линию случайно |
| **Статус словами + цветом + иконкой** | Не только цвет (дальтонизм), не только слово (быстрый скан) |
| **Минимум ввода** | Справочники, шаблоны, значения по умолчанию, гео и время — автоматически |
| **Честность данных** | Если координаты взяты от объекта, а не от GPS — это написано. Если фото из галереи — это видно |

---

## 2. Информационная архитектура

```
Вход / регистрация / 2FA
│
└── Приложение (после входа)
    ├── Карта  ←────────────────────────────┐
    │   ├── Слои, фильтры, поиск            │
    │   ├── Bottom sheet объекта            │
    │   │   ├── Паспорт                    │
    │   │   ├── Питание (путь, потребители)│
    │   │   ├── Фото (лента, съёмка)        │
    │   │   ├── История / дефекты          │
    │   │   └── Действия (статус, заземление, перемещение) 
    │   ├── Режим «Правка схемы» (админ)    │
    │   └── Режим «Схема» (однолинейная)    │
    ├── Обходы  (мой обход, маршруты, история)
    ├── Объекты (список/дерево, поиск)
    ├── Журнал  (переключения, действия, дефекты)
    ├── Синхронизация (очередь, конфликты)
    └── Профиль (сессии, 2FA, пароль)
        └── Администрирование (сотрудники, типы, настройки, аудит) — только admin
```

Мобильная навигация — **нижняя панель из 5 вкладок**: `Карта · Обход · Объекты · Журнал · Ещё`. На десктопе — левый сайдбар с теми же разделами.

## 3. Экран «Карта»

```
┌───────────────────────────────────────────┐
│ [🔍 Поиск объекта или кода]      [⚙️] [👤] │  ← компактный топбар
│ (Все) (КТП) (Ячейки) (Кукушки) (Аварии)  │  ← чипы-фильтры, скролл
├───────────────────────────────────────────┤
│                                           │
│        ● КТП-14        ◆ БКРУ-1           │
│           │                               │
│           └───────● КТП-15                │
│   ⬛ ПС-35/6 кВ                            │
│        ╲                                  │
│         ╲─── ▭ КСР-3      ▲ кукушка       │
│                                           │
│  ┌─────────────┐                          │
│  │ ● под напр. │  ← легенда (сворачивается)
│  │ ○ обесточен │                          │
│  │ ▲ ремонт    │                          │
│  └─────────────┘                          │
│                                    ┌────┐ │
│                                    │ ➕ │ │  ← FAB: контекстное действие
│  [🧭 Моё положение] [🗺 Схема]     └────┘ │
└───────────────────────────────────────────┘
```

**Поведение**
* Тап по объекту → bottom sheet в положении **peek** (24% высоты): название, тип, статус, путь питания одной строкой, 3 быстрых действия.
* Свайп вверх → **half** (55%): паспорт + вкладки. Ещё вверх → **full** (92%): фото на весь экран, история.
* Свайп вниз или тап по карте — закрыть. Кнопка «назад» на Android закрывает лист, а не приложение.
* Долгое нажатие на объекте — быстрые действия (статус, фото, переместить).
* Двойной тап — зум, щипок — масштаб, два пальца — поворот **отключён** (мешает в поле).
* Кластеризация при зуме < 14 (в единицах карты — настраивается), подписи кодов появляются при приближении.
* При офлайне: плашка сверху «Офлайн · 7 изменений ждут отправки» (жёлтая, не красная).

**Слои** (переключатель в боковом листе): объекты, линии питания, дефекты, обходы (мои/все), мобильные объекты, освещение, зоны (горизонты/борта), подложки (схема/снимок).

**Легенда** — компактная карточка внизу слева; на телефоне сворачивается в иконку «?», чтобы не закрывать карту.

## 4. Bottom sheet объекта

```
┌───────────────────────────────────────────┐
│              ▁▁▁▁▁                        │  ← ручка
│ ⚡ КТП-14              ● под напряжением  │
│ КТП · 6/0,4 кВ · гор. +120, борт северный │
│ ─────────────────────────────────────────  │
│ Питание: ПС-35/6 → ф.21К → БКРУ-1, яч.2 → │  ← кликабельная цепочка
│ ─────────────────────────────────────────  │
│ [📷 Фото]  [🔄 Статус]  [📍 Переместить]  │  ← 3 быстрых действия
│ ─────────────────────────────────────────  │
│ Паспорт │ Питание │ Фото 12 │ История     │  ← вкладки
│                                           │
│ • Мощность: 250 кВА                       │
│ • Зав. №: 448213                          │
│ • Введён: 12.04.2019                      │
│ • Дефектов: 2 (1 критичный)               │
│ • Последний обход: 28.10.2026, Петров П.П.│
└───────────────────────────────────────────┘
```

Вкладка **«Питание»**: upstream-цепочка, downstream-список потребителей с суммарной мощностью, кнопка «Показать на карте» (подсветка подграфа), «Что обесточится при отключении» — предварительный расчёт.

Вкладка **«Фото»**: сетка 3 в столбик, дата и автор на превью, кнопка камеры, переключатель «Все / Дефекты / Осмотры».

Вкладка **«История»**: единая лента — смена статуса, перемещение, фото, дефект, обход, правка паспорта; с иконками и автором.

---

## 5. Действия, требующие подтверждения

* **Смена статуса** — не модалка, а bottom sheet с крупными кнопками-состояниями и обязательным полем «Причина» (быстрые чипы: «плановое отключение», «авария», «ремонт», «по заявке»). Внизу — предупреждение: «Обесточатся 4 объекта» со списком.
* **Заземление** — отдельная кнопка с иконкой «⏚», красная рамка и текст «Убедитесь, что линия отключена и проверено отсутствие напряжения».
* **Перемещение кукушки** — карта в режиме выбора точки: «Укажите новое положение» + кнопка «Взять мои координаты»; после — комментарий и опциональное фото.
* **Удаление объекта** (админ) — ввод кода объекта для подтверждения, причина; необратимость не притворяемся: «объект останется в истории, но исчезнет из схемы».

## 6. Режим «Правка схемы» (только admin)

Отдельный режим с **постоянной красной/янтарной рамкой по периметру** и подписью «Режим правки схемы» — чтобы не спутать с просмотром.

* Инструменты в нижней панели: `Выбрать · Объект · Линия · Связь · Переместить · Удалить`.
* Рисование линии: тап по порту-источнику → тапы по точкам излома → тап по порту-приёмнику. Двойной тап — завершить. Вершины перетаскиваются, «отменить» — верхняя кнопка.
* Инспектор справа (на телефоне — лист): тип связи, роль (основная/резервная), марка, сечение, длина (авто из геометрии, с возможностью правки).
* **Живая валидация**: проблемные объекты подсвечиваются, внизу счётчик «3 предупреждения · 1 ошибка», список с переходом к проблеме.
* **Черновик/публикация**: изменения копятся, вверху «Черновик · 5 изменений», кнопка «Опубликовать» с обязательным комментарием; после публикации — снимок версии.
* Правка недоступна офлайн: баннер «Схему можно менять только онлайн» и инструменты неактивны.

---

## 7. Режим «Схема» (однолинейная)

Альтернативный вид того же графа: автоматическая раскладка «сверху вниз» от источников (алгоритм слоёв), шины горизонтально, отходящие вертикально, подписи — коды и напряжения. Для:
* работы внутри помещений (где карта не нужна);
* объяснения «почему обесточено»;
* печати/скриншота для отчёта.

Жесты: пан/зум, тап по узлу → тот же bottom sheet.

## 8. Обход

```
┌───────────────────────────────────────────┐
│ Обход · Западный №1          [⏸ Пауза]    │
│ Начато 08:12 · 4 из 12 объектов · офлайн  │
├───────────────────────────────────────────┤
│ ✅ КТП-14        норма          08:20     │
│ ⚠️ КТП-15        дефект (фото)  08:34     │
│ ⬜ ЯКУ-3         ожидает                  │
│ ⬜ БКРУ-1 яч.2   ожидает                  │
│                                           │
│ [📷 Снять] [✅ Норма] [⚠️ Дефект]         │
│              [Завершить обход]            │
└───────────────────────────────────────────┘
```

* Один объект — один экран с чек-листом (галочки: «внешний осмотр», «заземление», «пломбы» — настраивается по типу).
* QR-сканер в топбаре: «Подтвердить, что я на месте».
* Фото — от 1 до N, с авто-метаданными и водяным знаком.
* Прогресс сохраняется локально после каждого тапа (устойчивость к закрытию приложения).
* По завершении — сводка: объекты, находки, время, «Отправить» (или «уйдёт при появлении сети»).

## 9. Офлайн и синхронизация — как это выглядит

* Постоянный индикатор в топбаре: `● онлайн` / `● офлайн` (серый, спокойный) / `↻ синхронизация` (анимированный) / `⚠ 2 конфликта`.
* Тап по индикатору → экран «Синхронизация»: последний успех, размер очереди по типам (фото 4, статусы 2, обходы 1), кнопка «Отправить сейчас», список ошибок с человеческим текстом («Не хватает прав на объект — обратитесь к администратору»).
* Конфликты — отдельный список: «Кукушка ДГУ-7: вы переставили в 15:40, Сидоров — в 15:42. Оставлено положение Сидорова» + кнопка «Оставить моё» (для админа/диспетчера).
* Никаких модалок «Ошибка сети» — только спокойная плашка.

## 10. Дизайн-система

### 10.1 Токены (тёмная тема — базовая)

| Токен | Значение | Применение |
|---|---|---|
| `--bg` | `#0B1014` | фон приложения |
| `--surface-1` | `#121A21` | карточки, листы |
| `--surface-2` | `#182330` | приподнятые элементы, поля |
| `--border` | `#253242` | разделители, обводки |
| `--text-primary` | `#E6EDF3` | основной текст |
| `--text-secondary` | `#9FB0C0` | подписи |
| `--text-muted` | `#6B7A8A` | второстепенное |
| `--accent` | `#4C9AFF` | ссылки, активные элементы |
| `--accent-warm` | `#F5A524` | «внимание», резерв |

### 10.2 Статусы (цвет + иконка + слово)

| Статус | Цвет | Иконка | Слово |
|---|---|---|---|
| Под напряжением | `#2FBF71` | ● | «под напряжением» |
| Обесточено | `#6B7A8A` | ○ | «обесточено» |
| Резерв | `#3D8BFD` | ◆ | «резерв» |
| Ремонт | `#F5A524` | ▲ | «ремонт» |
| Авария/критичный дефект | `#F2545B` | ✕ | «авария» |
| Заземлено | `#A56BFF` | ⏚ | «заземлено» |

Светлая тема: те же смыслы, приглушённые оттенки на белом (`#FFFFFF`, `#F4F6F8`, обводки `#D8DEE6`), контраст проверен.

### 10.3 Типографика и размеры

* Шрифт: системный стек (`-apple-system, Segoe UI, Roboto`), цифры — моно (`JetBrains Mono` fallback `ui-monospace`) для кодов, табельных, номеров ячеек.
* Базовый 16 px; подписи 13–14; заголовок листа 18–20; крупные статусы 15 semibold.
* Радиусы: 12 px карточки, 16 px листы, 999 чипы.
* Сетка отступов: 4/8/12/16/24.
* Тач-цели: минимум 48 px, отступ между действиями ≥ 8 px.
* Bottom sheet: ручка 32×4, snap-точки 24% / 55% / 92%.

### 10.4 Компоненты

`StatusChip`, `AssetIcon` (по типу), `PowerPath` (цепочка), `BottomSheet`, `SegmentedControl`, `FilterChips`, `PhotoGrid`, `PhotoCapture`, `InspectionItem`, `DefectBadge`, `SyncIndicator`, `MapLegend`, `NumberPad` (для табельного/кодов), `EmptyState`, `ErrorState`, `ConfirmSheet`.

Состояния у каждого: обычное, нажатое, загрузка (skeleton), пусто, ошибка, недоступно (офлайн).

## 11. Desktop-версия (админ/диспетчер)

Три колонки: **список/фильтры (280 px) · карта (гибкая) · инспектор (360 px)**. Таблица объектов с виртуализацией, массовые операции, экспорт. Горячие клавиши: `/` поиск, `E` правка, `Esc` выход из режима, `Ctrl+Z` отмена последнего изменения в черновике. Журнал и аудит — таблицы с фильтрами и экспортом.

---

## 12. Тексты (microcopy)

* Пусто: «Пока нет объектов. Добавьте первый или импортируйте из прототипа».
* Офлайн: «Нет связи. Всё, что вы сделаете, сохранится и уйдёт автоматически».
* Конфликт: «Этот объект изменили с другого устройства. Мы сохранили обе версии — проверьте».
* Ошибка прав: «Схему может менять только инженер. Отправьте заявку администратору».
* Подтверждение удаления: «Удалить КТП-14? Объект исчезнет из схемы, история сохранится».
* Гео: «Координаты взяты от объекта, а не от GPS» (и наоборот).

---

## 13. Доступность и особые условия

* Контраст: текст ≥ 4.5:1, иконки ≥ 3:1; проверка в обеих темах.
* Дублирование цвета иконкой и подписью.
* Крупные шрифты в системе не ломают вёрстку (rem, без фиксированных высот).
* Работа в перчатках: без мелких свайп-зон у краёв, без двойных тапов в критичных действиях.
* Солнце: тёмная тема + высокий контраст; опция «максимальная яркость» не блокируется.
* Вибрация/звук — ненавязчиво, только для критичных подтверждений.

---

## 14. Чего в интерфейсе не будет

* Отдельных «страниц-таблиц» для каждого типа оборудования (как сейчас: Резерв, КСР, Мачты) — всё через единый реестр с фильтрами.
* Модальных окон на весь экран для простых действий — только bottom sheet.
* Нативного `confirm()` и toast-ошибок вместо объяснений.
* Скрытых жестов без альтернативы кнопкой.
* Светлой темы «по умолчанию» и белого фона ночью.
